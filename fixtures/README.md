# fixtures —— 演示模式新闻样例

**本目录所有条目均为虚构测试数据**：标题、链接、日期、摘要全部为编造，与任何真实的新闻、公司、产品无关，仅用于演示模式（`NEWS_SOURCE=demo`）下让 Agent 在不联网抓取的情况下可复现地运行。页面与 README 均标注"虚构测试新闻"。

- 每个来源一个 `.jsonl` 文件，每行一条 JSON：`news_id / title / url / published_at / source / summary`；
- `news_id`（N0001 起）在样例内唯一且固定，是简报引用可追溯性的锚点；
- 日期固定为 2026-10-15/16，不随运行日期平移（设计文档 D14）；
- 内容覆盖三类兴趣（AI Agent / 开源模型与工具 / 硬件与行业动态），保证"修改偏好后简报出现可解释差异"的演示路径。
